<!-- release-title: Branch Out -->

### Improvements

- Branch any conversation or highlighted passage into an independent thread, then move between focused thread and interactive canvas views without losing the original context.
- Run sibling branches in parallel with durable turns, unread activity, safe cancellation recovery, and state that survives reloads.
- Connect Codex, Claude, OpenRouter, or Ollama and choose models, reasoning levels, and fast mode independently for each branch while credentials stay within their local runtime boundary.
- Organize local work with projects, automatic chat titles, pinning, renaming, archiving, route-aware Back and Forward navigation, keyboard shortcuts, and a command palette.
- Read GitHub Flavored Markdown and use message copy, edit, retry, timestamps, and per-conversation scroll restoration.
- Install a signed, notarized universal macOS app that bundles its local data service and model runtime, keeps chats and files on your device, and updates without a separate development stack.
- Downloaded desktop updates now appear in a persistent once-per-session notification with direct actions to review changes or restart.

### Fixes

- Fixed cancellation, retry, reload, and runtime-restart recovery so interrupted turns recover cleanly without duplicate messages or stalled sibling branches.
- Fixed duplicate desktop shortcuts and overlapping new-chat creation.
- Fixed macOS window controls, packaged renderer reloads, updater dependencies, and signed-release verification.

### Misc

- Monte Carlo is now open source under the MIT License with a private vulnerability-reporting process.
